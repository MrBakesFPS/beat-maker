# Accessibility

- **Themes**: Preferences > Display offers Dark, High Contrast (WCAG AAA contrast for all text) and Light. Every view and the standard widgets follow the palette.
- **Interface scale**: 100 to 175%.
- **Screen readers**: controls and knobs carry names; a track-and-selection description is exposed to assistive technology and read on demand with **Ctrl+Shift+/**; status messages can be spoken (switchable). Screen reader output depends on the platform's accessibility backend.
- **Keyboard navigation** of the edit window: Up and Down select tracks, Left and Right move the playhead by the grid value, Shift with the arrows extends the selection, Shift+Return selects a track's clips, Shift+M, Shift+S and Shift+R mute, solo or arm the selected track. The focused edit window shows an accent outline, and every command is reachable from the palette (**Ctrl+Shift+P**).
- **Tooltips** on every control, and a searchable Keyboard Shortcuts window (**Ctrl+/**).
